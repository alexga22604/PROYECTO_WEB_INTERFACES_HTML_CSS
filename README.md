# Mi instituto: IES Tetuán de las Victorias

Prototipo web informativo (Fase 2 del proyecto: HTML5 + CSS3) de **Alejandro Gadea Vicente**.
Sigue el diseño realizado previamente en Figma.

## Páginas

| Archivo | Contenido | Maquetación |
|---|---|---|
| `index.html` | Inicio: presentación, experiencia en el centro y favicono | Flexbox |
| `centro.html` | El centro: ubicación, instalaciones, servicios y entorno | **Flexbox** |
| `estudios.html` | Mis estudios: recorrido, proyecto destacado y lo aprendido | **CSS Grid** |

## Estructura de carpetas

```
├── index.html
├── centro.html
├── estudios.html
├── css/     base.css (común) · inicio.css · centro.css · estudios.css
├── fonts/   DM Sans y Open Sans (OFL, alojadas en local)
└── img/     imágenes, favicono e iconos/
```

## Diseño

- Colores: `#0B3D2E` · `#247A50` · `#5CDB97` · `#F4F7F5`
- Tipografías: DM Sans (títulos, menú) y Open Sans (texto)
- Ilustraciones: las del prototipo de Figma. Iconos: estilo Lucide (licencia ISC).
